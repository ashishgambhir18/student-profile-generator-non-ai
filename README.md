# Student Profile Generator V14

Features:
- Built-in statement banks for 11 subjects
- Editable original profile and separate AI-adjusted/refined profile
- AI only runs when explicitly requested
- Final saved profile must be 366–390 characters
- Child list appears in left navigation
- Any child can be opened in any order
- Saved profiles and working selections/drafts are persisted in browser local storage so the same browser can resume later without re-uploading the class list
- Start a new class / subject clears the browser-saved class

Deploy `app.py` on Streamlit Community Cloud. Keep `OPENAI_API_KEY` in Streamlit Secrets.
